What a signal means

For each stock and day, the model looks at the last {{ run.info.config.window }} trading sessions and estimates the probability of each outcome over the next {{ run.info.horizon }} sessions:

  • BUY: return above +threshold
  • SELL: return below −threshold (NEPSE has no retail short selling, so read this as "exit or avoid")
  • HOLD: anything in between

The threshold is max({{ run.info.min_move|pct:0 }}, {{ run.info.k_vol }} × 20-session volatility × √{{ run.info.horizon }}), so a volatile stock needs a bigger move to count. The class with the highest bias-adjusted log probability is shown (bias SELL {{ run.info.bias.0|floatformat:1 }}, BUY {{ run.info.bias.2|floatformat:1 }}, chosen on validation folds).
